CHEMVERSE turns chemistry into something you can explore with your hands: click elements, search compounds, draw molecules, build reactions and run safe virtual experiments.

How it is built

Python and Django (MVT architecture), SQLite3, HTML5, CSS3, JavaScript, Bootstrap 5, Chart.js and JSON APIs – organised into 15 Django apps.

About the data

Melting and boiling points are reference values at 1 atm in °C. Values marked Approximate vary between sources; substances that decompose or sublime are labelled instead of being given an invented value; masses in [brackets] are mass numbers of the most stable isotope. Safety notes are summaries – always read the official Safety Data Sheet.
